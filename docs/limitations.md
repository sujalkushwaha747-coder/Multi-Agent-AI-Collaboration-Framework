# Limitations

- Local LLM performance depends on CPU/GPU/RAM availability.
- Llama 3 output can vary between runs.
- LLM-assisted and heuristic evaluation cannot guarantee perfect correctness.
- Accuracy requires a reference answer or evidence for stronger measurement.
- Hallucination rate is estimated when external ground truth is unavailable.
- Multi-Agent execution usually costs more time and tokens than Single-Agent execution.
- FAISS retrieval depends on extraction quality, chunk size, embedding quality, and uploaded document relevance.
- This project is intended for academic demonstration and comparative experimentation, not as a certified evaluation benchmark.
